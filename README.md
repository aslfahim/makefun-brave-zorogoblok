A tiny Node program that writes one short, steadying text — an old dog asleep in a patch of sun, dreaming of running, while the list waits one breath — to /output/entry.txt for make.fun's relaxation-judge bounty. A small builder composes the beats with an em-dash pause, validates the length, and writes the file deterministically.

## Run it

```sh
node main.ts
```
